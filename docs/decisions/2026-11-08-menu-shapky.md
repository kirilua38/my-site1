# Меню шапки: четыре пункта без выпадающего списка
**Дата:** 2026-11-08
**Заменяет:** решение по умолчанию «Пункты меню „Курси“, „Навчання та сертифікація“, „Працевлаштування“ остаются, но пока никуда не ведут» из `docs/plans/stage1-copy.md`.
**Контекст:** сайт переделываем под свежий дизайн. В шапке было шесть пунктов: три никуда не вели, а «Документи водія» раскрывался в список из двух страниц — «КОД 95» и «ЧІП-КАРТА».
**Решение:** в меню шапки на всех страницах четыре пункта: «Головна», «Код 95», «Чіп-карта», «Контакти». Выпадающего списка нет.
**Почему:**
- разделов «Курси», «Навчання та сертифікація», «Працевлаштування» на сайте не будет;
- в «Документи водія» всего две страницы — выпадающий список для них лишний.

**Отвергнуто:**
- оставить три пункта без ссылок, как на этапе 1 — разделов не будет;
- оставить «Документи водія» выпадающим списком — для двух страниц он лишний.

**Пересмотреть, если:** страниц документов станет больше и они перестанут помещаться в строку меню.
