# Решение: карта офисов на «Контактах» — библиотека Leaflet в проекте

**Дата:** 2026-10-25
**Статус:** принято владельцем (вариант 1 из трёх, шаг 27б плана `docs/plans/stage1-copy.md`).

## Контекст
- На странице «Контакти» оригинала под блоком «Зв'яжіться з нами!» — интерактивная карта Украины с тремя офисами (Тернопіль, Київ, Дніпро).
- В оригинале она сделана на библиотеке Leaflet 1.9.4, которую страница грузит с `unpkg.com`, подложка — плитки OpenStreetMap, контур Украины грузится с `raw.githubusercontent.com`.
- По `CLAUDE.md` стек — чистые HTML, CSS и JavaScript; новая библиотека — только через решение.

## Решение
- **Leaflet 1.9.4 лежит в проекте**, в `vendor/leaflet/`: `leaflet.js`, `leaflet.css`, карта исходников `leaflet.js.map`, картинки `images/`, лицензия `LICENSE` (BSD-2-Clause: можно хранить и раздавать, если файл лицензии рядом).
  - Взято из реестра npm (`leaflet-1.9.4.tgz`). Сверено: архив совпадает с контрольной суммой npm (`sha512-nxS1ynzJ…74PA==`), `leaflet.js` и `leaflet.css` — с хешами, которые указаны в коде оригинала (`sha256-20nQCchB…lZBo=`, `sha256-p4NxAoJB…BMY=`).
  - Файлы библиотеки не правим. Это исключение из правил `CLAUDE.md` «цвета — только переменные из `variables.css`» и «картинки — в `img/`»: у `vendor/leaflet/leaflet.css` свои цвета (кнопки «+/−», всплывающие окна, ссылки), отметки офисов — картинки из `vendor/leaflet/images/`. На этапе 2 (ребрендинг) видимые цвета карты перекрываем своими правилами в `css/contacts.css`, а отметки при необходимости рисуем сами.
  - Только на `contacts.html`, и не сразу: стили и скрипт библиотеки подгружает `js/map.js`, когда до карты почти докрутили (за 300px). Кто смотрит только адрес и телефон вверху страницы, библиотеку не скачивает.
- **Контур Украины** — `data/ukraine.geo.json`, тот же файл, что в оригинале (репозиторий johan/world.geo.json, данные Natural Earth 1:110m, общественное достояние). Контур грубый (98 точек), Крым — в составе Украины.
- **Подложка** — плитки `tile.openstreetmap.org` с обязательной подписью «© OpenStreetMap» и ссылкой на их страницу авторских прав.
- **Наш код** — `js/map.js`: три отметки (во всплывающем окне — город и адрес в формате блока контактов), контур, вписывание Украины в окно карты. Цвета контура берутся из CSS-переменных.
  - Отличия от оригинала: колесо мыши, как и там, листает страницу; на сенсорных экранах карту не двигаем одним пальцем — иначе палец на карте не листает страницу; при смене ширины окна карта вписывается заново, только если посетитель её не трогал; при «меньше анимаций» в системе масштаб меняется без анимации.

## Отвергнуто
- **Как в оригинале — Leaflet с `unpkg.com`, контур с GitHub.** Сайт зависел бы от двух чужих серверов, которые не обещают работать для чужих сайтов; GitHub к тому же ограничивает частоту запросов.
- **Статичная картинка карты со ссылками на Google Maps.** Без скриптов и внешних запросов, но карту не подвинуть и не приблизить — это не копия оригинала.
- **Встроенная карта Google My Maps.** Нужна карта в аккаунте Google владельца, внешний сервис со своими cookie.

## Последствия
- Единственный внешний запрос — плитки OpenStreetMap: браузер посетителя обращается к их серверам (они видят IP посетителя). Для небольшого сайта их политика использования плиток это разрешает; при большом трафике нужен свой или платный сервер плиток — меняется одна строка адреса в `js/map.js`.
- Если OpenStreetMap недоступен, карта остаётся без подложки, но с отметками и контуром.
- Обновить Leaflet — заменить файлы в `vendor/leaflet/` новой версией из npm и сверить контрольные суммы.
- Когда посетитель доходит до карты, страница догружает ~160 КБ (библиотека и её стили); другие страницы не меняются.
